## Preserve the final partial chunk
Fix chunked(values, size). Return consecutive non-overlapping lists with at most size elements, preserving a final partial chunk. Empty input returns []. Reject a non-positive size with ValueError. Do not mutate values.

General review rule: describe boundary conditions and input preservation separately from the patch. Do not treat a passing sample as proof of every possible input. The test runner is the only authority on this fixture's deterministic checks.

## Keep keys from both count dictionaries
Fix merge_counts(left, right). Return a new dictionary containing the union of keys and the sum of each key's integer counts. Missing keys contribute zero. Negative and zero counts are valid; preserve their keys. Do not mutate either argument.

General review rule: describe boundary conditions and input preservation separately from the patch. Do not treat a passing sample as proof of every possible input. The test runner is the only authority on this fixture's deterministic checks.

## Include the final complete moving-average window
Fix moving_average(values, width). Return arithmetic means of every consecutive complete window of width elements, including the last possible window. Return [] when values is shorter than width. Reject non-positive width with ValueError. Do not pad partial windows or mutate input.

General review rule: describe boundary conditions and input preservation separately from the patch. Do not treat a passing sample as proof of every possible input. The test runner is the only authority on this fixture's deterministic checks.
