normalize_items(items) strips whitespace and lowercases SKU strings, sums quantities for duplicate normalized SKUs, accepts only positive non-bool integers, and rejects empty SKUs or invalid quantities with ValueError.
apply_event(stock, held, event) returns (new_available, new_held), never mutating any input, including nested items. Stock keys are already normalized. Reservation IDs strip surrounding whitespace but are case-sensitive. reserve normalizes the basket and checks all stock before allocating; insufficient or missing stock raises ValueError. Replaying an active reservation with an identical normalized basket is an idempotent no-op; the same ID with a different basket raises ValueError. release restores quantities by addition, removes the reservation, and is a no-op if the ID is unknown. Unknown event kind or empty ID raises ValueError. An ID may be reserved again after release. replay applies events in order and returns {available, held}.
